# Algorithm

1. Start the program.
2. Read the number of NFA states and input symbols.
3. Read the NFA transition table.
4. Consider q0 as the initial DFA state.
5. For each DFA state and input symbol, collect all reachable NFA states.
6. Create a new DFA state for every new set of NFA states.
7. Repeat until no new DFA states are obtained.
8. Display the DFA transition table.
9. Stop the program.
