# Algorithm

1. Start the program.
2. Read the arithmetic expression.
3. Scan for * and / operations.
4. Take the operands on the left and right of the operator.
5. Generate a temporary variable and print the operation.
6. Remove the processed operation from the expression.
7. Repeat until no * or / remains.
8. Scan for + and - operations.
9. Generate temporary variables and print each operation.
10. Display the final result.
11. Stop the program.
