# Algorithm

1. Start the program.
2. Read the statement string.
3. Split the input using ; and , delimiters.
4. Check whether a statement is variable = constant.
5. Store the constant value in the variable table.
6. Otherwise check whether it is variable = variable.
7. Copy the known value of the right-hand variable to the left-hand variable.
8. Print the updated variable value.
9. Continue until all statements are processed.
10. Stop the program.
